User Profile App

Приложение с тремя разделами: профиль, галерея и контакты. На вкладке профиля — аватар, ссылки на соцсети, информация об учёбе и работе, теги интересов, кнопка скачивания резюме и кнопка «Нравится» со счётчиком, который не сбрасывается при закрытии приложения.

  • Галерея из 30 фотографий — нажмите любую, чтобы открыть в полный экран с поддержкой зума щипком
  • Раздел контактов: нажмите на номер — и звонок начнётся прямо из приложения
  • Тёмная и светлая тема — переключатель в шапке, выбор сохраняется между запусками

Полноэкранный просмотр галереи с мультитач-зумом реализован через пакет photo_view. Сетевые изображения кэшируются через cached_network_image — повторных загрузок при прокрутке не происходит.

Счётчик «Нравится» хранится в shared_preferences и переживает перезапуск приложения. Переключение темы построено на ValueNotifier<ThemeMode>: вся тема меняется реактивно без перезапуска приложения. Звонок из раздела контактов выполняется через url_launcher по схеме tel:.

FlutterCafé

Меню кафе: пять категорий и 26 блюд с описанием ингредиентов. Найдите любое блюдо через строку поиска — результаты обновляются на каждое нажатие. Добавляйте позиции в корзину, выбирайте количество порций и отслеживайте итоговую сумму.

  • Бейдж на иконке корзины показывает количество позиций — обновляется мгновенно
  • Экран детали блюда: выберите количество порций перед добавлением
  • Тёмная и светлая тема с сохранением выбора между запусками

Корзина реализована как ValueNotifier<List<CartItem>> — реактивное хранилище в памяти, разделяемое между всеми экранами без сторонних библиотек управления состоянием. Поиск фильтрует список блюд методом where() прямо на модели данных при каждом изменении строки.

Бейдж на иконке вкладки корзины собран через Stack + Positioned, подписанный на нотификатор корзины. Тема и корзина управляются двумя независимыми ValueNotifier, оба слушаются через ValueListenableBuilder.

FitDay

Трекер тренировок: восемь упражнений с отметкой выполнения. Нажмите на упражнение — запустится 30-секундный таймер, который можно поставить на паузу или сбросить. Следите за прогрессом по упражнениям, калориям и времени. Завершите день одной кнопкой — тренировка сохранится в историю.

  • Прогресс-бары по трём целям: упражнения, калории, время тренировки
  • Настройки: цель по калориям (100–1000), звук, вибрация и уведомления
  • История тренировок: просматривайте прошлые занятия, удалите ненужные долгим нажатием

Всё состояние приложения сосредоточено в одном FitDayNotifier extends ValueNotifier<FitDayState> с иммутабельным объектом состояния — все четыре экрана подписаны на единый источник данных, что исключает рассинхронизацию. Это принципиальное отличие от предыдущих лабораторных, где состояние было разделено по отдельным нотификаторам.

Таймер построен на Timer.periodic из dart:async без AnimationController. Удаление упражнения вызывается через onLongPress с подтверждением в AlertDialog. Иконка приложения кастомная — сгенерирована через flutter_launcher_icons.

EventHub

Планировщик событий: добавляйте дела с категорией, датой и временем. Пять категорий — Учёба, Спорт, Развлечения, Работа, Личное. Фильтруйте список, ищите по названию или описанию, сортируйте по дате или названию.

  • Смахните карточку в сторону, чтобы удалить событие — действие можно отменить
  • Редактирование: нажмите на событие, откройте детали и измените любое поле
  • Вкладка «Статистика»: круговые индикаторы показывают долю каждой категории в процентах

Свайп для удаления реализован через виджет Dismissible с отменой действия через SnackBar. Форма добавления и редактирования открывается как ModalBottomSheet и содержит системные диалоги showDatePicker и showTimePicker — нативный UI платформы без сторонних пакетов.

Список событий отображается через GridView.builder с двумя колонками. Фильтрация по категории — через ChoiceChip, сортировка — через PopupMenuButton. Статистика вычисляется в реальном времени из того же EventsNotifier с иммутабельным состоянием — отдельного слоя для аналитики не потребовалось.
