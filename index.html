Каждый пуш в ветку main автоматически запускает сборку через GitHub Actions: приложение компилируется в релизный APK, подписывается Keystore-ключом (хранится в GitHub Secrets) и публикуется в GitHub Releases. Ссылки на скачивание ниже всегда ведут на последнюю актуальную версию.

git push → main → GitHub Actions → flutter build apk --release → Подпись Keystore → GitHub Releases

Лабораторная работа №2

User Profile App

Flutter-приложение с профилем пользователя, галереей и контактами. Реализует адаптированную дизайн-систему EAM: glassmorphism-карточки, тёмный фон, акцентный цвет. Поддерживает переключение тёмной и светлой темы с сохранением выбора между сессиями.

  • Профиль: аватар, автовычисление возраста, информационные карточки (ВК, Telegram, GitHub, учёба, работа), теги интересов, скачивание резюме в PDF
  • Кнопка «Нравится» с персистентным счётчиком через SharedPreferences
  • Галерея из 30 фотографий с полноэкранным просмотром и мультитач-зумом
  • Список контактов с возможностью совершить звонок напрямую из приложения

Лабораторная работа №3

FlutterCafé

Приложение-меню кафе на Flutter с полным каталогом блюд, умным поиском и корзиной. Дизайн выполнен в EAM Design System (glassmorphism). Поддерживает переключение тёмной и светлой темы с автоматическим сохранением предпочтения пользователя.

  • 5 категорий и 26 блюд с описаниями ингредиентов и изображениями
  • Корзина с добавлением/удалением позиций, подсчётом суммы и бейджем на иконке вкладки
  • Глобальный поиск по всем блюдам в реальном времени через TextField
  • Экран деталей блюда с выбором количества порций перед добавлением в корзину

Лабораторная работа №4

FitDay

Трекер ежедневных тренировок на Flutter: список упражнений с отметкой выполнения, отслеживание прогресса к целям, история занятий и встроенный таймер обратного отсчёта. Реализует EAM Design System с поддержкой тёмной и светлой темы.

  • 8 упражнений с иконками и Switch для отметки выполнения; тап открывает 30-секундный таймер с Start/Pause/Reset и автоматическим SnackBar
  • Прогресс-бары по трём целям: упражнения, калории, время тренировки
  • Настройки: уведомления, звук, вибрация и Slider цели по калориям (100–1000 ккал)
  • Вкладка «История»: кнопка «Завершить день» сохраняет тренировку и сбрасывает список; долгий тап → удаление упражнения через AlertDialog

Лабораторная работа №5

EventHub

Приложение-планировщик событий на Flutter: каталог дел с категориями, фильтрацией, поиском и статистикой. Добавление и редактирование событий через BottomSheet с выбором даты и времени. Реализует EAM Design System с переключением темы.

  • GridView событий (2 колонки) с фильтрацией по 5 категориям через ChoiceChip: Учёба, Спорт, Развлечения, Работа, Личное
  • Поиск по названию, описанию и месту в реальном времени; сортировка по дате, названию или категории
  • Добавление и редактирование через BottomSheet (TextField, DropdownButton, DatePicker, TimePicker); свайп для удаления с undo через SnackBar
  • Вкладка «Статистика»: CircularProgressIndicator для каждой категории с долей событий в процентах
